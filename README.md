# CJAJLK Nature V1.5

Application web francophone, thème bleu nuit et cyan. 46 recettes/méthodes, 6 guides de prudence. Deux modes de fabrication, profils familiaux, matériel, coûts et stock local, sauvegarde JSON.

## Utilisation

- `index.html` : lancer dans VS Code Live Server ou publier à la racine de GitHub Pages.
- `CJAJLK_Nature_V1_5_Standalone.html` : fichier autonome à ouvrir dans Chrome, utile pour des essais locaux.
- La V1.5 conserve la clé locale `cjajlk-nature-v1-local` et le schéma de sauvegarde `version:1`.

## Sécurité

Les préparations sont des exemples domestiques, à évaluer avant utilisation. Aucun mélange ménager n'est présenté comme désinfectant. Respecter les instructions du fabricant, le profil/allergies et le matériel indiqué ; ne jamais combiner Javel et vinaigre. Les soins n'ont pas de statut de traitement et l'app ne remplace pas un professionnel. Les sources figurent dans Réglages & sources.

## Indépendance

Aucun vendeur imposé, aucune commission ni classement sponsorisé.
